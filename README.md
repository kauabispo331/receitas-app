## 📱 Recursos do App

✅ Visualizar receitas completas com ingredientes e modo de preparo
✅ Buscar receitas por categoria
✅ Adicionar receitas aos favoritos
✅ Calcular porções automaticamente
✅ Listar ingredientes para comprar
✅ Visualizar tempo de preparo e dificuldade
✅ Compartilhar receitas com amigos
✅ Avaliar e comentar receitas

---

## 🚀 Como Usar

1. Clone o repositório
2. Abra no Android Studio
3. Configure um emulador Android ou conecte seu dispositivo
4. Execute o projeto
5. Explore o menu de receitas!
